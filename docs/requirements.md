# Weekly Report

## Objetivo
Desenvolver um sistema sistema tem como objetivo auxiliar no traking das suas tarefas 
diarias, saber o que você fez, está fazendo e vai fazer, tendo essas informações
registradas com histórico é mais fácil saber o que dizer na daily e também registrar
marcos importantes do que a pessoa realizou no projeto

---

## Quem vai utilizar o sistema?
O usuário pode ser qualquer pessoa que queria trakear suas tarefas

## Qual o maior problema hoje?
Saber o que dizer para pessoas de fora quais foram os resultados atingidos dentro 
do projeto.

---

## Requisitos funcionais

 - RF001 Cadastrar projeto
 - RF002 Editar projeto
 - RF003 Inativar projeto
 - RF004 Reativar projeto
 - RF005 Listar os projetos ativos
 - RF006 Listar os projetos inativos

 - RF007 Cadastrar tarefa
 - RF008 Editar tarefa
 - RF009 Inativar tarefa
 - RF010 Reativar tarefa
 - RF011 Listar tarefas ativas
 - RF012 Listar tarefas inativas

 - RF013 Cadastrar usuário
 - RF014 Editar usuário
 - RF015 Desativar usuário
 - RF016 Reatiiivar usuário

 - RF017 Emitir relatório por projeto
 - RF018 Histórico da tarefa

## Requisitos não funcionais

 - RNF001 O sistema deve possuir autenticação
 - RNF002 O tempo de resposta deve ser inferior a 2 segundos
 - RNF003 O sistema deve ser responsívo
